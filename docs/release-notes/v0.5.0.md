# windforce-core v0.5.0 release note

## Environment variable prefix migration

Core-owned environment variables now use `WINDFORCE_CORE_*`. Rename each
existing `WINDFORCE_LITE_<SUFFIX>` setting to
`WINDFORCE_CORE_<SUFFIX>`; the suffix and value do not change.

For example:

```dotenv
# Before
WINDFORCE_LITE_DATABASE_URL=postgres://postgres@postgres:5432/windforce_core?sslmode=disable

# v0.5.0+
WINDFORCE_CORE_DATABASE_URL=postgres://postgres@postgres:5432/windforce_core?sslmode=disable
```

The new name is authoritative. If both names have non-empty values,
`WINDFORCE_CORE_*` wins. If the new name is absent or empty, v0.5.x and v0.6.x
fall back to the matching `WINDFORCE_LITE_*` name. The legacy aliases may be
removed no earlier than v0.7.0.

The compatibility fallback covers the runtime flags backed by environment
variables, the repository-local control helper, Vite and UI-guide settings,
Make targets, and Docker Compose interpolation. `.env.example`, current
documentation, and CI use only the new names so fresh installations do not
create more legacy configuration.
